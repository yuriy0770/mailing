# 📭 Сервис управления рассылками

Проект "Сервис управления рассылками" предоставляет удобные инструменты для управления email-рассылками, администрирования и получения статистики. Он поможет компаниям эффективно взаимодействовать с клиентами и анализировать результаты своих кампаний.

## Установка и запуск

1. Клонируйте репозиторий:

    ```bash
    git clone <url-репозитория>
    cd <директория проекта>
    ```

2. Создайте и активируйте виртуальное окружение:

    ```bash
    python -m venv venv
    source venv/bin/activate  # Linux/macOS
    venv\Scripts\activate     # Windows
    ```

3. Установите зависимости:

    ```bash
    pip install -r requirements.txt
    ```

4. Настройте параметры в `settings.py`, включая подключение к базе данных и кешу.

5. Примените миграции:

    ```bash
    python manage.py migrate
    ```

6. Создайте группу менеджеров (если не создана автоматически):

    ```bash
    python manage.py create_manager_group
    ```

7. Запустите сервер:

    ```bash
    python manage.py runserver
    ```

8. Перейдите в браузере по адресу: `http://localhost:8000`

## Модели

- **Пользователь**: кастомная модель на базе `AbstractUser` с полями email, аватар, номер телефона и страна. Авторизация по email.
- **Рассылка**: с необходимыми полями, включая владельца.
- **Сообщение**: связанное с рассылкой с необходимыми полями.
- **Получатель рассылки**: содержит данные получателей и принадлежит пользователю.
- **Попытка рассылки**: хранит информацию об отправках сообщений.

Все модели снабжены миграциями и имеют связи, соответствующие Техническому Заданию.

## Контроллеры и шаблоны

- Контроллеры регистрации, входа, выхода и управления профилем пользователя.
- CRUD контроллеры для рассылок, сообщений и получателей рассылок с шаблонами.
- Страницы используют базовый шаблон с общими блоками.
- URL маршруты корректно настроены.

## Интерфейс

- Кнопки входа, выхода и регистрации, меняющиеся в зависимости от состояния пользователя.
- Навигация с переходом к основным разделам для авторизованных пользователей.
- Страницы с отчетами по рассылкам и управлением рассылками, сообщениями и получателями.
- Отдельная страница для просмотра попыток рассылок.

---

## Права доступа

- Реализована группа «Менеджеры» с набором прав на управление рассылками.
- Обеспечен доступ пользователей только к своим данным через фильтрацию QuerySet'ов и проверки в шаблонах.
- В модели добавлены кастомные права через класс `Meta`.
- В контроллерах переопределён `form_valid()` для автоматической привязки текущего пользователя как владельца.

---

## Кеширование

- Настроено серверное кеширование с использованием Redis.
- Отчёты по рассылкам кешируются для повышения производительности.
- Кеширование применяется для тяжелых или часто запрашиваемых вьюх.
